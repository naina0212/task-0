## Description
This task focuses on solving six Python programming questions using basic Python concepts, Pandas, CSV data analysis, and Matplotlib data visualization.

The project uses the provided student_performance.csv dataset. The solutions perform data analysis and generate visualizations of student performance.

## Setup Instructions

Make sure Python 3.x is installed.

Install the required libraries using:

pip install pandas matplotlib

## How to Run

Run the solutions using the following commands:

python q1.py
python q2.py
python q3.py
python q4.py
python q5.py
python q6.py
